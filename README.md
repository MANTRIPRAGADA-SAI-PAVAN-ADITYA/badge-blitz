# badge-blitz

A tiny Python toolkit for everyday developer tasks.

## Tools included

| Script | What it does |
|--------|-------------|
| `timer.py` | Countdown timer with sound alert |
| `colors.py` | Convert between HEX, RGB, and HSL |
| `slugify.py` | Turn any string into a URL-safe slug |

## Usage

```bash
python timer.py 25        # 25-minute pomodoro timer
python colors.py "#ff6b6b" # convert HEX → RGB → HSL
python slugify.py "Hello World!" # → hello-world
```

## Requirements

Python 3.8+, no external dependencies.
